# Dokumentacja projektu

Dokumentacja do oddania znajduje sie w tym folderze.

| Plik | Opis |
|------|------|
| `dokumentacja.pdf` | **Glowny dokument do oddania** |
| `dokumentacja.tex` | Zrodlo LaTeX (edycja + kompilacja) |
| `DOKUMENTACJA.md` | Wersja markdown |
| `JAK_URUCHOMIC.md` | Jak odpalic aplikacje |
| `screenshots/` | Zrzuty ekranu (01–04) |

Aplikacja Laravel: `../ProjektAplikacje/`

## Przebudowa PDF

```powershell
cd Dokumentacja
pdflatex dokumentacja.tex
```
